# WARNO Map Updater
## Description

This is a little tool i created to automate the process of updating/uploading map (mods) for WARNO. Mostly made for my own convenience, but I think others might enjoy it, too :)

## Getting Started

### Dependencies

* Windows >=10
* .net Framework 9.0 installed


### Installing

* The Tool is a single portable *.exe - place it in the warno installation folder (where you find the WARNO.exe) and start it from there :)
  

### Executing program

* Start the exe and follow the instructions, duh...
